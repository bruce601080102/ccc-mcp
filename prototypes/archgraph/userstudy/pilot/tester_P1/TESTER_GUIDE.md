# 內部預試說明（測試者用）

## 這次預試是什麼

- 你是本專案的**非作者內部測試者**。目的是檢查題目能不能被看懂、材料有沒有缺漏、標準答案有沒有矛盾。
- 這**不是**新手驗證。你的結果**不能**用來證明新手看得懂，也**不能**用來證明產品已通過任何驗證。
- 只用你拿到的材料作答。不要上網查資料、不要問 AI、不要看另一位測試者的作答。

## 你會拿到什麼

| 位置 | 內容 |
|---|---|
| `blocks/block1_notes/`、`blocks/block2_bookmarks/`、`blocks/block3_todos/` | 三個區塊，每個區塊一份材料與一份題目 |
| `blocks/<區塊>/material/` | 該區塊的材料。HTML 用瀏覽器開；`summary.md` 用文字編輯器開 |
| `blocks/<區塊>/questions.md` | 該區塊的 12 題 |
| `response_sheets/<區塊>.json` | 該區塊的作答表。請填這份，不要改欄位名稱 |
| `TIMING_AND_ERROR_LOG.csv` | 計時與錯誤理解紀錄表 |
| `FEEDBACK_FORMAT.md` | 問題回報格式 |

## 流程

1. **依序完成三個區塊**：block1 → block2 → block3。不可跳過，也不可回頭改已送出的答案。
2. 每個區塊開始時：
   - 在該區塊的作答表中，把 `start_time` 填成現在時間（HH:MM:SS）。
   - 只開啟該區塊 `material/` 的材料。
3. 依 `questions.md` 順序作答，**逐題填寫**，填完一題再看下一題。
4. 不確定就寫「不確定」，不要猜。
5. 完成後把 `end_time` 填成現在時間（HH:MM:SS），並把 `questions_asked_for_help` 填成你向協調者求助的次數（沒有就填 0）。
6. 每遇到下列情況，在 `TIMING_AND_ERROR_LOG.csv` 加一列（每列一個情況）：
   - 材料與題目的詞語對不上。
   - 你以為材料說的是 A，但實際上找到的是 B。
   - 材料的兩個地方說法不一致。
   - 你自己的答案前後矛盾。
   - 你需要猜才能回答。
7. 材料本身讓你覺得畫面有問題（看不懂、找不到、像有錯）時，依 `FEEDBACK_FORMAT.md` 回報。

## 作答格式

- **Q01、Q03–Q08、Q11、Q12（清單題）**：每項寫成功能名稱或檔案路徑，與材料中的名稱**完全相同**。沒有就寫「無」。
- **Q02**：寫一個檔案路徑。
- **Q09（判斷表）**：每個功能、每個欄位只能填「是」、「否」或「不確定」。
- **Q10（能否合併）**：
  - `answer`：只能填「能」或「不能」。
  - `blocking`：只勾選**會阻擋合併**的原因，從題目列出的選項中原樣選取（寫在陣列中）。
  - `actions`：待執行的動作，從題目列出的選項中原樣選取（寫在陣列中）。
- **不作答的欄位請保留 `null`**，不要刪除欄位，也不要改成空字串。「無」是一個答案，不是空白。

## 計時

- 區塊時間是 `start_time` 到 `end_time`，不含閱讀本說明的時間。
- 單一區塊上限 15 分鐘。超過時照實寫，並在 `notes` 說明。

## 禁止事項

- 不修改任何材料檔案。
- 不把材料或作答表貼到網路上，也不把作答表給別人看。
- 作答期間不與另一位測試者討論答案。
- 不向協調者以外的人求助。
