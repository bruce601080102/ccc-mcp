# 預試問題回報格式

每個問題一段，依下列欄位填寫。沒有的欄位留空，不要刪除欄位名稱。

```
編號：F-<測試者代號>-<序號>，例如 F-P1-03
測試者：P1 或 P2
區塊：例如 block1_notes
位置：材料檔名，例如 blocks/block1_notes/material/TASK-0003.html，核准條件區塊
題號：例如 Q10（若與題目無關填 —）
我看到的：
我預期看到的：
實際的差異：
嚴重程度：阻擋作答 / 造成誤答 / 增加時間 / 文字不清楚
是否影響答案：是 / 否 / 不確定
補充：
```

**不要**寫：修改建議、產品功能要求、與本次預試無關的意見。這些請另外寫在作答表的 `notes`，協調者會另行處理。
